# 2006ICT Tetris - Milestone 1

JavaFX/Maven Tetris project for 2006ICT Object Oriented Software Development.

## Run

Requires JDK 21 and Maven.

```bash
mvn clean javafx:run
```

## Controls

- Left / Right: move tetromino
- Up: rotate clockwise
- Down: soft drop
- Space: hard drop
- P: pause/resume

## Milestone 1 features

- Splash screen
- Main menu
- Configuration screen
- Top-10 high-score screen
- 10x20 default game field
- Smooth timer-driven falling
- Tetromino movement and rotation
- Full-row clearing including multiple rows
- Pause/resume with visible paused message
- Exit confirmation dialog
- OOP examples: interface, abstract class, record, enum, enhanced switch and enhanced for loop
